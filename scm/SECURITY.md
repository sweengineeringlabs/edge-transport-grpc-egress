# Security Policy

## Supported Versions

Only the latest minor release receives security fixes. Releases before 1.0 may break between minors, so
older minors are not patched: upgrade to the latest.

| Version | Supported |
|---------|-----------|
| 0.8.x   | Yes       |
| < 0.8   | No        |

When a new minor is released this table is updated in the same change.

## Reporting a Vulnerability

If you discover a security vulnerability in Edge, please report it responsibly.

1. Do not open a public issue
2. Email the maintainers at engineers@swelabs.io with a description of the vulnerability
3. Include steps to reproduce, if possible
4. Allow reasonable time for a fix before public disclosure

We will acknowledge receipt within 48 hours and aim to provide a fix or mitigation within 7 days.
